<h3 style="color:#0056b3; font-size: 24px; margin-top: 0;">Oracle Code Assistant</h3>

I was part of the AI/ML R&D team behind <a href="https://www.oracle.com/news/announcement/oracle-code-assist-can-help-developers-build-applications-faster-with-ai-2024-05-07/">Oracle Code Assist</a>, Oracle’s enterprise-grade coding assistant powered by large language models and optimized for Java, SQL, and OCI-based application development. I contributed to the development of foundation models that generate context-aware code, explain complex logic, suggest upgrades, and create tests — all integrated seamlessly within developer IDEs. The tool was featured at Oracle CloudWorld 2024 and recognized across industry press.

<h3 style="color:#0056b3; font-size: 24px; margin-top: 0;">OCI Vision, Oracle Cloud’s First AI Service</h3>

I led R&D on Oracle’s first production-scale document understanding and image classification models for <a href="https://www.oracle.com/artificial-intelligence/vision/">OCI Vision</a>, launched as part of the <a href="https://www.oracle.com/news/announcement/oci-ai-services-launch-2021-11-03/">OCI AI Services suite</a>. My work focused on building deep learning systems for layout analysis, table detection, and visual classification — enabling automation across documents and images in finance, logistics, and manufacturing. This initiative laid the foundation for Oracle’s applied AI offerings and continues to support enterprise-grade solutions.
