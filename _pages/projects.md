## Active Projects 

**Oracle Code Assistant** I was part of the AI/ML R&D team behind Oracle Code Assist](https://www.oracle.com/news/announcement/oracle-code-assist-can-help-developers-build-applications-faster-with-ai-2024-05-07/), Oracle’s enterprise-grade coding assistant powered by large language models and optimized for Java, SQL, and OCI-based application development. I contributed to the research and development of foundation models that enable Code Assist to generate context-aware code, explain complex logic, suggest upgrades, and create tests — all integrated seamlessly within developer IDEs like IntelliJ and VS Code. Our R&D efforts focused on aligning LLM capabilities with real-world enterprise workflows, internal coding standards, and cloud-specific patterns. Code Assist was featured at Oracle CloudWorld 2024.
